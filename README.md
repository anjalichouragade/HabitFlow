# HabitFlow 🐬

A simple and user-friendly daily habit tracker to create, manage, and track your habits, progress, and streaks.

🔗 **Live demo:** https://anjalichouragade.github.io/HabitFlow/

## Why I built this

I wanted a habit tracker that feels personal to me instead of using a generic app, so I built my own.

## Features

- Create your own habits
- Mark habits as done each day
- Track your progress and streaks

## Built with

- HTML
- CSS
- JavaScript

Hosted on GitHub Pages.

## Run it locally

1. Download or clone this repository
2. Open `index.html` in your browser
